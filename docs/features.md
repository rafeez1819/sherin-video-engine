# Features

| Feature | Description |
|---|---|
| Image-first pipeline | Keyframes are supplied or generated before transitions are synthesized |
| Circular buffer | Frames rotate through a bounded 60-slot buffer |
| KuLexicon | Maps prompt concepts to subjects, objects, and visual attributes |
| Transition strategies | Blend, hold, and pan frame synthesis |
| Resolution profiles | 1080p, 2K, and 4K |
| Output formats | MP4 and WebM |
| Pluggable keyframes | Supply a callback to connect an external image service |
